# Floor maps

This directory contains one JSON per zone of the building. Each file describes
the clickable layer that is rendered on top of the corresponding floor plan
SVG in the reservation wizard (`Step2SeatMap`).

## Files

| File          | Zona ID | Codigo | Descripción         | Background SVG               |
|---------------|---------|--------|---------------------|------------------------------|
| `pb.json`     | 1       | PB     | Planta Baja         | `src/assets/mapas/piso_PB.svg` |
| `mz.json`     | 2       | MZ     | Mezanine            | `src/assets/mapas/piso_MZ.svg` |
| `p3.json`     | 3       | P3     | Piso 3              | `src/assets/mapas/piso_3.svg`  |
| `p9.json`     | 4       | P9     | Piso 9              | `src/assets/mapas/piso_9.svg`  |

## Schema

```jsonc
{
  "zonaId": 2,
  "codigoZona": "MZ",
  "nombre": "Mezanine",
  "edificio": "ATC Monterrey",
  "viewBox": "0 0 1440 810",
  "background": "/src/assets/mapas/piso_MZ.svg",
  "tipoLabels": {
    "1": "Estacion de trabajo",
    "2": "Sala de juntas",
    "5": "Area especial"
  },
  "spaces": [
    { "id_espacio": 154, "codigo": "MZ001", "nombre": "Estación MZ001",
      "tipo": 1, "shape": "circle", "x": 220, "y": 180, "r": 11 },
    { "id_espacio": 468, "codigo": "MZSJ-115", "nombre": "Sala Mitras",
      "tipo": 2, "shape": "rect", "x": 1025, "y": 90, "w": 110, "h": 80 }
  ]
}
```

### Field reference

- `viewBox`: SVG viewBox used for both the background and the markers.
- `background`: path (relative to project root) of the floor plan image.
- `tipoLabels`: dictionary used by the wizard to render type labels.
- `spaces[]`: each marker on top of the plan.
  - `shape: "circle"` requires `x`, `y`, `r`
  - `shape: "rect"` requires `x`, `y`, `w`, `h` (top-left anchored)

## How to refine positions by hand

The initial positions were auto-generated by `scripts/generate-floor-maps.mjs`
and are only a starting grid (they don't follow the real building layout yet).

To refine them visually:

1. Run the dev server (`npm run dev`) and log in as any user.
2. Open `/reservar?edit=1` in the browser. The seat map enters **edit mode**.
3. Drag any marker to its real position on the plan.
4. Click **Export JSON** in the floating toolbar — the updated JSON for the
   currently selected zone is shown in a modal.
5. Copy the JSON and paste it back into the corresponding file
   (`pb.json` / `mz.json` / `p3.json` / `p9.json`).

Alternative: edit the JSON directly. Coordinates are in the SVG `viewBox`
space (`0..1440` horizontal, `0..810` vertical), where `(0,0)` is the
top-left corner of the plan.

## Regenerating from scratch

If `Espacio.csv` changes (e.g. new spaces added in production), regenerate
the JSON layouts and re-tune by hand:

```bash
node scripts/generate-floor-maps.mjs                   # uses default CSV path
node scripts/generate-floor-maps.mjs ./path/to/csvs    # custom location
```

The script preserves no manual edits — back up the previous JSONs first if
you want to keep tuned positions.
